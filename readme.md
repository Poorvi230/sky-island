# 🏝️ Sky Island

This is a 2-D vertical jumper game. The bird goes up while collecting coins and different power-ups, bounces from island to island, to reach the upper atmosphere where the light changes..

Can be played on both mobile and desktop(recommended)

## Features

- Different types of platforms, they gonna keep appearing until the birf drops ded 
- Has a dynamic atmosphere > the sky bg shifts colors and darkness as altitude increases.
- Has STARS in the bg!!
- Power ups > Jetpack, Coin Magnet, coins, bubble shield 
- Beware of flying obstacles UwU
- Space key on desktop can shoot LASERS to kill obstacles
- Web Audio API used for sound effects, no external audio files 

## Controls

### Desktop
    | Action | Key |
    |---|---|
    | **Move Left** | `A` or `Left Arrow` |
    | **Move Right** | `D` or `Right Arrow` |
    | **Shoot Laser** | `Spacebar` |

 ### Mobile

- **Tap Left / Right half of screen:** Steer bird left or right.
